## 为什么使用链表
* 数组空间可能不够用
* 太大数组浪费空间
* 删除，插入操作效率低
## 链表
* 链表由节点组成
* 节点由数据部分和指针部分组成
## 特点
* 节点不要求在内存中连续存储
* 普通非循环单链表的尾节点，其 next 指针为 NULL
* 指向第一个节点的指针称为头指针
## 代码实现
简单代码，原理
```cpp
#include<stdio.h>
struct node{
    int value;
    struct node*next;
};
int main(){
    struct node a;  //一个节点
    struct node b;

    struct node*list = NULL;  //空链表

    list=&a; //list链表，含有一个节点
    a.next = &b;
    b.next = NULL;
}
```
## 链表类型
* 没有头节点
1、带头结点的单链表：更为高效，方便
2、不带头结点的单链表：不浪费，每个成员都包含数据
* 分类
1、单链表
2、双向链表
* 有没有环
1、链表
2、循环链表

## 链表基础操作
* 创建空链表
```cpp
#include<stdio.h>
#include<stdlib.h>
struct node{
    int value;
    struct node*next;
};
//创建链表（带头结点的）
struct node* list_create(){
    struct node* list=(struct node *)malloc(sizeof(struct node));
    //malloc 申请的动态内存需要用 free 释放；局部自动变量的生命周期通常随作用域结束
    if(list==NULL){
        return NULL;
    }
    list->next=NULL;
    return list;
}
```
