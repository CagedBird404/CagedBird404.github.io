## 用途与思路

利用指数二进制展开计算模幂。

## 使用前提与复杂度

要求 e≥0、mod>0。GCC 的 __int128 用于避免两个 64 位模数余数相乘溢出。

**复杂度：** O(log e) 时间，O(1) 空间。

<!-- ACM_VALIDATION -->

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

i64 modPow(i64 a, i64 e, i64 mod) {
    if (mod <= 0 || e < 0) throw invalid_argument("invalid modulus or exponent");
    a %= mod;
    if (a < 0) a += mod;
    i64 result = 1 % mod;
    while (e) {
        if (e & 1) result = (__int128)result * a % mod;
        a = (__int128)a * a % mod;
        e >>= 1;
    }
    return result;
}
```
