## 用途与思路

双端队列支持两端插入删除和下标访问。

## 使用前提与[复杂度](/posts/acm-keywords/#complexity)

front、back、pop 必须先确认非空；at 会检查边界。

**[复杂度](/posts/acm-keywords/#complexity)：** 两端操作与随机访问 O(1)，中间插删 O(n)。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

int main() {
    deque<int> values(3, 7);
    values.push_back(9);
    values.push_front(1);
    cout << values.front() << ' ' << values.back() << '\n';
    values.pop_front(); values.pop_back();
    values.insert(values.begin() + 1, 5);
    values.erase(values.begin());
    cout << values.at(0) << '\n';
}
```
