## 用途与思路

求不超过正整数 x 的最大 2 的幂的指数。

## 使用前提与复杂度

明确是 floor(log2 x)，不是按距离最近；x=0 返回 −1。

**复杂度：** O(log x) 时间，O(1) 空间。

<!-- ACM_VALIDATION -->

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

int floorLog2(unsigned long long x) {
    int answer = -1;
    while (x) { ++answer; x >>= 1; }
    return answer;
}
```
