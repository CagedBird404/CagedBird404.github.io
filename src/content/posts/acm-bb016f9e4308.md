## 用途与思路

按拓扑序累加 DAG 中源点到汇点的路径数。

## 使用前提与复杂度

原代码把入度和出度的变量含义写反；对 x→y 应让 indegree[y]++、outdegree[x]++。

**复杂度：** O(n+m) 时间，O(n+m) 空间。

> 原代码保留了 `#define int long long` 的写法；它会替换所有后续 int，可能改变接口与内存占用。独立复用时更建议用 `using i64 = long long` 并显式选择类型。

## 代码

```cpp
#include <bits/stdc++.h> 
using namespace std;
#define int long long                 
#define endl '\n'                     
#define all(x) (x).begin(), (x).end() 

constexpr int MOD = 80112002;

void solve()
{
    int n,m;
    cin >> n >> m;
    vector<vector<int>> a(n+1);
    vector<int> inp(n+1);
    vector<int> outp(n+1);
    for(int i = 0;i < m ;i ++)
    {
        int x,y;
        cin >> x >> y;
        inp[x]++;
        outp[y]++;
        a[x].emplace_back(y);
    } 
    queue<int> q;
    vector<int> dp(n+1);
    for(int i=1;i<=n;i++)
    {
        if(!inp[i]) 
        {
            q.push(i);
            dp[i] = 1;
        }
    }
    while(!q.empty())
    {
        auto k = q.front();
        q.pop();
        for(auto p : a[k])
        {
            dp[p] = (dp[p] + dp[k]) % MOD;
            inp[p]--;
            if(!inp[p]) q.push(p);
        }
    }
    int ans = 0;
    for(int i = 1;i<=n;i++)
    {
        if(!inp[i])
        {
            ans = (ans + dp[i])%MOD;
        }
    }
    cout << ans;
}

signed main()
{
    cin.tie(0)->ios::sync_with_stdio(0);                
    cout << setiosflags(ios::fixed) << setprecision(2); 
    int TT = 1;
    //cin >> TT; 
    while (TT--)
    {
        solve(); 
        //cout << endl;
    }
}
```
