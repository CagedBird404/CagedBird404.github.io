## 用途与思路

动态数组：连续存储、随机访问、尾部追加。

## 使用前提与[复杂度](/posts/acm-keywords/#complexity)

resize(n,val) 只用 val 填充新增位置；扩容会让旧[迭代器](/posts/acm-keywords/#iterator)失效。emplace_back 不保证总比 push_back 快。

**[复杂度](/posts/acm-keywords/#complexity)：** 访问 O(1)，尾部追加均摊 O(1)，中间插删 O(n)。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

int main() {
    vector<int> values{1, 2, 3};
    vector<vector<int>> matrix(5, vector<int>(6, 2));  // 5 行 6 列。
    values.push_back(4);
    values.resize(6, 3);
    int index = 1;
    // 不要求保序时，用末尾元素覆盖待删除位置。
    values[index] = values.back(); values.pop_back();
    for (int x : values) cout << x << ' ';
    cout << '\n';
}
```
