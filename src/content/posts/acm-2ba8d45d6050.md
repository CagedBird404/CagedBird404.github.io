## 用途与思路

用倍增恒等式计算斐波那契数。

## 使用前提与复杂度

这里采用模运算版本，避免原始 long long 很快溢出；n≥0，1≤mod≤10^9。

**复杂度：** O(log n) 时间，O(log n) 递归空间。

<!-- ACM_VALIDATION -->

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

pair<i64, i64> fibonacciPair(i64 n, i64 mod) {
    if (n == 0) return {0, 1 % mod};
    auto [a, b] = fibonacciPair(n / 2, mod);
    i64 c = a * ((2 * b - a + mod) % mod) % mod;
    i64 d = (a * a + b * b) % mod;
    return (n & 1) ? make_pair(d, (c + d) % mod) : make_pair(c, d);
}
```
