## 用途与思路

用试除法判断整数是否为质数。

## 使用前提与复杂度

小于 2 不是质数，适用于中小整数；大范围 64 位判素应使用 Miller–Rabin。

**复杂度：** O(√n) 时间，O(1) 空间。

<!-- ACM_VALIDATION -->

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

bool isPrime(i64 n) {
    if (n < 2) return false;
    if (n % 2 == 0) return n == 2;
    for (i64 d = 3; d <= n / d; d += 2) if (n % d == 0) return false;
    return true;
}
```
