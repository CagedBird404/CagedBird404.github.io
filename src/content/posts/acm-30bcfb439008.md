## 用途与思路

求严格上升子序列长度；相等元素不延长序列。

## 使用前提与复杂度

lower_bound 对应严格上升，非降序改用 upper_bound；tails 本身不一定是原数组的一条子序列。

**复杂度：** O(n log n) 时间，O(n) 空间。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

int lisLength(const vector<i64>& a) {
    vector<i64> tails;
    for (i64 x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return (int)tails.size();
}
int ldsLength(vector<i64> a) {
    // 使用降序比较器，避免对 LLONG_MIN 取负溢出。
    vector<i64> tails;
    for (i64 x : a) {
        auto it = lower_bound(tails.begin(), tails.end(), x, greater<i64>());
        if (it == tails.end()) tails.push_back(x); else *it = x;
    }
    return (int)tails.size();
}
```
