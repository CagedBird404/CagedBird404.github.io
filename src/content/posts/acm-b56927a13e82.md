## 用途与思路

每个物品最多选一次，在容量以内最大化价值。

## 使用前提与复杂度

容量倒序，确保当前物品不会重复使用；这是“不超过容量”，不是“恰好装满”。

**复杂度：** O(nV) 时间，O(V) 空间。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

// items 中每一项为 {体积, 价值}；体积必须为正。
i64 knapsack01(int capacity, const vector<pair<int, i64>>& items) {
    vector<i64> dp(capacity + 1, 0);
    for (auto [cost, value] : items) {
        for (int j = capacity; j >= cost; --j) {
            dp[j] = max(dp[j], dp[j - cost] + value);
        }
    }
    return dp[capacity];
}
```
