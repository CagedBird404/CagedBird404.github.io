## 用途与思路

这里记录一个常见模型：从 0 出发经过每个点一次的最小代价路径，不要求回起点。

## 使用前提与复杂度

dp[mask][u] 表示访问集合 mask、最后停在 u；n≤18 更稳妥，不能只看位数能否存下。

**复杂度：** O(n²2^n) 时间，O(n2^n) 空间。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

i64 hamiltonPath(const vector<vector<i64>>& w) {
    int n = (int)w.size();
    if (n == 0) return 0;
    const i64 INF = (1LL << 60);
    vector<vector<i64>> dp(1 << n, vector<i64>(n, INF));
    dp[1][0] = 0;
    for (int mask = 1; mask < (1 << n); ++mask)
        for (int u = 0; u < n; ++u) if (dp[mask][u] != INF)
            for (int v = 0; v < n; ++v) if (!(mask >> v & 1))
                dp[mask | (1 << v)][v] = min(dp[mask | (1 << v)][v], dp[mask][u] + w[u][v]);
    return *min_element(dp.back().begin(), dp.back().end());
}
```
