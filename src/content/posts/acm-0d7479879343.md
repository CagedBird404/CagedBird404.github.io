## 用途与思路

双堆动态维护第k大值的学习实现与使用笔记。

## 使用说明

这里记录我的实现和理解。使用时，我会先确认输入输出、下标和数据范围，再按具体题目调整。

> **使用时我会注意：** 这个实现加入了值为 0 的哨兵，可能影响负数数据；通用第 k 大实现不应依赖该哨兵。

> 我在这份代码里用了 `#define int long long`。使用时要留意它对接口和内存的影响；也可以改用 `using i64 = long long`，显式选择需要的整数类型。

## 代码

```cpp
#include <bits/stdc++.h> 
using namespace std;
#define int long long                 
#define endl '\n'                     
#define all(x) (x).begin(), (x).end() 

constexpr int MOD = 1e9 + 7;

priority_queue<int> mx; // 大顶堆
priority_queue<int,vector<int>,greater<int>> mi; // 小顶堆

int now;
void qwq()
{
    if(mi.size() < now)
    {
        mi.push(mx.top());
        mx.pop();
    }
    if(mi.size() > now)
    {
        mx.push(mi.top());
        mi.pop();
    }
}
void solve()
{
    int n,w,num;
    cin >> n >> w;
    mx.push(0);
    for(int i = 1;i <= n;i++)
    {
        now = max(1ll,i*w/100);
        cin >> num;
        if(num >= mx.top())
        {
            mi.push(num);
        }
        else mx.push(num);
        qwq();
        cout << mi.top() << " ";
    }
}

signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);                
    cout << setiosflags(ios::fixed) << setprecision(2); 
    int TT = 1;
    //cin >> TT; 
    while (TT--)
    {
        solve(); 
        //cout << endl;
    }
}
```
