## 用途与思路

子序列可以不连续，但必须保持相对顺序。

## 使用前提与复杂度

dp 的第 i 行表示前 i 个字符，访问原字符串时用 i−1。

**复杂度：** O(nm) 时间，O(m) 空间。

<!-- ACM_VALIDATION -->

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

int lcsLength(const string& a, const string& b) {
    vector<int> dp(b.size() + 1);
    for (char x : a) {
        int diagonal = 0;
        for (int j = 1; j <= (int)b.size(); ++j) {
            int old = dp[j];
            if (x == b[j - 1]) dp[j] = diagonal + 1;
            else dp[j] = max(dp[j], dp[j - 1]);
            diagonal = old;
        }
    }
    return dp.back();
}
```
