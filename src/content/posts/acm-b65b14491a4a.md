## 用途与思路

每种物品可重复选择，求容量内最大价值。

## 使用前提与复杂度

容量正序，允许本轮再次使用同一物品；所有体积必须大于 0。

**复杂度：** O(nV) 时间，O(V) 空间。

<!-- ACM_VALIDATION -->

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

i64 unboundedKnapsack(int capacity, const vector<pair<int, i64>>& items) {
    vector<i64> dp(capacity + 1);
    for (auto [cost, value] : items)
        for (int j = cost; j <= capacity; ++j)
            dp[j] = max(dp[j], dp[j - cost] + value);
    return dp[capacity];
}
```
