## 用途与思路

给定一个起点，找出这个起点到其他所有点的最短路径 条件：图的边权值不能为负数

## 使用说明

这里记录我的实现和理解。使用时，我会先确认输入输出、下标和数据范围，再按具体题目调整。

给定一个起点，找出这个起点到其他所有点的最短路径
条件：图的边权值不能为负数
每次从未确定的点中选出路径最短的点，再通过他找他的邻居
1、起点距离记为 0，其他点设为无穷大
2、每次选出一个“最近但未访问”的点
3、用它“松弛”（relax）所有邻居：
时间复杂度：O((m+n)log(n))

> **使用时我会注意：** 边权必须非负，距离类型与 INF 要覆盖最大路径和。

> 我在这份代码里用了 `#define int long long`。使用时要留意它对接口和内存的影响；也可以改用 `using i64 = long long`，显式选择需要的整数类型。

## 代码

```cpp
/*
给定一个起点，找出这个起点到其他所有点的最短路径
条件：图的边权值不能为负数
每次从未确定的点中选出路径最短的点，再通过他找他的邻居

1、起点距离记为 0，其他点设为无穷大

2、每次选出一个“最近但未访问”的点

3、用它“松弛”（relax）所有邻居：

时间复杂度：O((m+n)log(n))
*/
#include <bits/stdc++.h> 
using namespace std;
#define int long long                 
#define endl '\n'                     
#define all(x) (x).begin(), (x).end() 

constexpr int MOD = 1e9 + 7;

void solve()
{
    int n, m, s;
    cin >> n >> m >> s;
    vector<vector<pair<int ,int>>> a(n + 1);
    for(int i = 0;i < m;i++)
    {
        int u, v, w;
        cin >> u >> v >> w;
        a[u].push_back({v, w});
    }

    vector<int> wf(n + 1, 1e18);
    wf[s] = 0;
    priority_queue<pair<int, int>, vector<pair<int ,int>>, greater<pair<int ,int>>> pq;
    pq.push({0, s});
    while(!pq.empty())
    {
        pair<int ,int> p = pq.top();
        pq.pop();
        int v = p.second;
        int w = p.first;
        if(w > wf[v]) continue;

        for(auto [u, f] : a[v])
        {
            if(f + w < wf[u])
            {
                wf[u] = f + w;
                pq.push({wf[u], u});
            }
        }
    }
}

signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);                
    cout << setiosflags(ios::fixed) << setprecision(2); 
    int TT = 1;
    //cin >> TT; 
    while (TT--)
    {
        solve(); 
        //cout << endl;
    }
}
```
