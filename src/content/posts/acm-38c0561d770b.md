## 用途与思路

给定一个起点，找出这个起点到其他所有点的最短路径 条件：图的边权值不能为负数

## 使用说明

这是原有学习代码的整理版。先查看下方代码中的输入输出和变量约定；题目专用实现不自动等同于通用模板。

给定一个起点，找出这个起点到其他所有点的最短路径
条件：图的边权值不能为负数
每次从未确定的点中选出路径最短的点，再通过他找他的邻居
1、起点距离记为 0，其他点设为无穷大
2、每次选出一个“最近但未访问”的点
3、用它“松弛”（relax）所有邻居：
时间复杂度：O((m+n)log(n))

> **易错点：** 边权必须非负，距离类型与 INF 要覆盖最大路径和。

> 原代码保留了 `#define int long long` 的写法；它会替换所有后续 int，可能改变接口与内存占用。独立复用时更建议用 `using i64 = long long` 并显式选择类型。

## 代码

```cpp
/*
给定一个起点，找出这个起点到其他所有点的最短路径
条件：图的边权值不能为负数
每次从未确定的点中选出路径最短的点，再通过他找他的邻居

1、起点距离记为 0，其他点设为无穷大

2、每次选出一个“最近但未访问”的点

3、用它“松弛”（relax）所有邻居：

时间复杂度：O((m+n)log(n))
*/
#include <bits/stdc++.h> 
using namespace std;
#define int long long                 
#define endl '\n'                     
#define all(x) (x).begin(), (x).end() 

constexpr int MOD = 1e9 + 7;

void solve()
{
    int n, m, s;
    cin >> n >> m >> s;
    vector<vector<pair<int ,int>>> a(n + 1);
    for(int i = 0;i < m;i++)
    {
        int u, v, w;
        cin >> u >> v >> w;
        a[u].push_back({v, w});
    }

    vector<int> wf(n + 1, 1e18);
    wf[s] = 0;
    priority_queue<pair<int, int>, vector<pair<int ,int>>, greater<pair<int ,int>>> pq;
    pq.push({0, s});
    while(!pq.empty())
    {
        pair<int ,int> p = pq.top();
        pq.pop();
        int v = p.second;
        int w = p.first;
        if(w > wf[v]) continue;

        for(auto [u, f] : a[v])
        {
            if(f + w < wf[u])
            {
                wf[u] = f + w;
                pq.push({wf[u], u});
            }
        }
    }
}

signed main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);                
    cout << setiosflags(ios::fixed) << setprecision(2); 
    int TT = 1;
    //cin >> TT; 
    while (TT--)
    {
        solve(); 
        //cout << endl;
    }
}
```
