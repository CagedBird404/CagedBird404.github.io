## c++的引用

原文件：`基础/面向对象/c++的引用.cpp`

```cpp
/*
引用作用：给变量起别名
引用和指针区别：引用只是起别名，不占内存
语法：数据类型 &别名 = 原名

例：
int a = 10;
int &b = a;
b = 20;
那么输出a时，结果也是20
本质上就是让a和b有相同的地址

引用注意事项：
1、引用必须初始化
例： int &b; //错误
2、引用一旦初始化后，就不可以更改
例：
int a = 10;
int &b = a;
int c = 20;
b = c;   //这属于赋值操作，不是换

引用做函数参数
作用：函数传参时，可以让形参修饰实参

例：
int Swap(int &a,int &b)
{
    int temp = a;
    a = b;
    b = temp;
}

引用本质：
int &b = a;
本质上是 int* const b = &a;
这也是不能更改的原因，因为他已经是固定地址了

常量引用
作用：常量引用主要用来修饰形参，防止形参改变实参
例：
const int &ref = 10;
加上const后 编译器将代码修改为 int temp = 10; &ref = temp;
意思就是创建一个临时变量，将这个变量的地址给ref
加入const后变成只读状态，不可以修改
*/
#include<bits/stdc++.h>
using namespace std;
void show(const int &val) //防止其进行更改
{
    cout << val << endl;
    cout << val << endl;
}
int main()
{
    int a = 100;
    show(a);
    cout << a << endl;
}
```

## 内存分区模型

原文件：`基础/面向对象/内存分区模型.cpp`

```cpp
/*
内存大致划分为四个区
1.代码区： 存放函数体的二进制代码
2.全局区： 存放 全局变量 和 静态变量 和 常量
3.栈区： 由编译器自动分配释放，存放函数的参数值，局部变量等
4.堆区： 由程序员分配和释放，若程序员不释放，程序结束时由操作系统回收
注： 不同区域存放的数据，赋予不同的生命周期，给我们更大的灵活编程

一、程序运行前
未执行前分为两个区
代码区：
1、存放CPU执行的机器指令
2、代码区是共享的，目的是对于被频繁执行的程序，只需要在内存中有一份代码就行
3、代码区是只读的，只可以读取，不能更改

全局区：
1、全局变量和静态变量存放在此（对于在main函数等里面的都叫局部变量，不在函数中就为全局变量）
（1）局部变量：int a = 1;（非全局区）
（2）全局变量：在函数外面
（3）静态变量：static int a = 1;（全局区）
（4）常量：（全局区）
        1、字符串常量(int)&"hello world"
        2、const修饰变量：
           const修饰的全局变量
           const修饰的局部变量
2、全局区还包括了常量区，字符串常量，和其他常量

二、程序运行后
运行后分为两个区

栈区：（栈区数据由编译器管理开辟和释放）
注意事项：不要返回局部变量的地址
例：
int* func(int b) <--- 形参数据在栈区
{
    int a = 10;  <--- 局部变量在栈区(带局部的就在栈区)
    return &a;
}
int main()
{
    int *p = func();
    cout << *p << endl;     第一次可以正常打印数字，是因为编译器做了保留
    cout << *p << endl;     第二次这个数据就不再保留了（32位只会保留一次，64可以多次）
}

堆区：（由程序员分配和释放，程序结束操作系统回收）
例：
int* func()        （利用new可以将数据开辟到新区）
{
    int *p = new int(10);     （指针本质上也是全局变量，放在栈上，指针保存的数据放在堆区）
    return p;                 （堆区的数据对应地址在栈中，地址可以在变，但是不同地址对应的堆区数据不变）
}
int main(){
    int *p = func();
    cout << *p << endl;
}
*/

//以下是new的基本语法
#include<bits/stdc++.h>
using namespace std;

//new的基本语法
int* func()
{
    int *p = new int(10);   //new返回的是该类型数据的指针
    return p;
}
void test()
{
    //创建一个数组，在堆区
    //返回数组首地址
    int *arr = new int[10];
    for(int i = 0;i < 10;i++)
    {
        arr[i] = i + 100;
        cout << arr[i] << endl;
    }
    //释放数组
    delete[] arr;
}
int main()
{
    int *p = func();
    cout << p << endl;
    cout << *p << endl;
    //堆区数据由程序员操控
    //如果想释放堆区数据，利用关键字 delete
    delete p;
    cout << *p << endl;//已经被释放
    test();
}
```
