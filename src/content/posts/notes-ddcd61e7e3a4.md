## 二维前缀和

先预处理前缀和，就可以用 O(1) 时间查询任意矩形区域的元素和。

构建公式是“左 + 上 − 左上 + 自己”，减去左上是为了扣除重复累加的部分。这里使用从 1 开始的下标，并预留第 0 行、第 0 列为 0。

```cpp
sum[i][j] = sum[i][j - 1] + sum[i - 1][j] - sum[i - 1][j - 1] + arr[i][j];
```

例如：

| 原数组 | 对应前缀和 |
| --- | --- |
| 3，1，−2 | 3，4，2 |
| 5，−3，4 | 8，6，8 |
| 3，6，−2 | 11，15，15 |

设左上角为 (a,b)，右下角为 (c,d)，满足 a≤c、b≤d：

```cpp
sum[c][d] - sum[a - 1][d] - sum[c][b - 1] + sum[a - 1][b - 1]
```

查询 (2,2) 到 (3,3) 得到 15−2−11+3=5。

## 二维差分

如果要给某个矩形区域内的所有元素加上 v，可以先在差分数组的四个位置打标记，再做二维前缀和恢复。

```cpp
void add(int a, int b, int c, int d, int v)
{
    diff[a][b] += v;
    diff[a][d + 1] -= v;
    diff[c + 1][b] -= v;
    diff[c + 1][d + 1] += v;
}
```

数组要预留 c+1、d+1 所需的边界空间。
